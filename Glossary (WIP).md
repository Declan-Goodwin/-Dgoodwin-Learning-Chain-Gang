<h1> A </h1> 
<h4> Artificial Intelligence (AI) </h4>
- The field of creating computer systems that can perform tasks that typically require human intelligence, such as understanding language, recognizing patterns, solving problems, making decisions, and learning from experience. <br>
<h4> Application Programming Interface (API) </h4>
- A set of rules and specifications that allows one software application to communicate with another. An API defines how a program can request information or ask another system to perform an action, as well as the format of the response. <br>
